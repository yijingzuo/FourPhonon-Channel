# License audit

## Upstream FourPhonon

The official FourPhonon v1.1 source archive contains the GNU General Public
License, version 3 (GPL-3.0-only).  GPL-3.0 permits use, study, modification,
and redistribution, including redistribution of modified source, provided that
the applicable GPL conditions are met.  Those conditions include preserving
copyright and license notices, identifying modifications, licensing covered
derivative work under GPL-3.0, and providing corresponding source when object
code is conveyed.

FourPhonon's README also requests citation of the FourPhonon software paper and
the foundational three- and four-phonon papers.  The sampling version documents
an additional sampling-method citation.  These references are listed in the
top-level README and `CITATION.cff`.

## Distribution decision for v0.1.0

This repository does not redistribute the complete FourPhonon source tree.  It
ships a focused source patch against official FourPhonon v1.1, independently
written Python analysis tools, documentation, tests, and compact reference
data.  The repository is distributed under GPL-3.0-only and includes the full
license text.

This is a technical license audit, not legal advice.
