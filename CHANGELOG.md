# Changelog

## 0.1.0 — 2026-10-06

- Added event-level acoustic/optical composition bookkeeping for three-phonon and four-phonon scattering.
- Added per-mode channel outputs and numerical closure diagnostics.
- Added validation, summary, comparison, and plotting tools.
- Added a compact validated MgTe reference dataset and automated tests.

This release is a patch and analysis-tool distribution; it does not redistribute the complete FourPhonon source tree.
